# AppleReferenceLab

Status: **planned; buildable project not yet created**.

Purpose: a project-owned macOS probe app that renders standard SwiftUI/AppKit controls with minimal modifiers so the team can capture state/appearance behavior consistently.

Initial scenes:
- Buttons
- Toggle / Slider
- Text input
- Pickers
- Sidebar
- Toolbar
- Menu / Popover
- Window
- Accessibility states

Capture matrix:
- Light / Dark
- Active / Inactive
- Normal / Hover / Pressed / Focused / Disabled / Selected
- control-size variants where applicable
- accent variants
- transparency/contrast accessibility settings
- resize, scroll, open/close transitions

The actual macOS/Xcode project should be created on a Mac during M0. Reference captures must follow the repository asset policy.
