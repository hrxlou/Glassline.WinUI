# AppleReferenceLab Capture Procedure

Status: **procedure defined; no captures taken yet**.

This is the operating procedure for an interactive macOS 26 reference session. It exists because the
capture matrix was previously prose. Prose produces a different set of screenshots every session and
leaves `research/measurements/measurement-ledger.csv` unable to cite a stable source, which means no
row could honestly be classified `Observed`.

## What the session must produce

`capture-manifest.csv` enumerates the required captures — 9 scenes × 8 variants = **72 captures**. It
is generated by `CaptureMatrix` in `ReferenceLabCore` and pinned by a test, so it cannot drift from
the code. Each row's `capture_id` is the identifier a ledger row cites as `source_id`.

Per scene, per appearance (Light and Dark):

| Window state | Accessibility mode | Purpose |
|---|---|---|
| active | `default` | baseline geometry and material |
| inactive | `default` | inactive-window material response |
| active | `reduce-transparency` | material fallback under Reduce Transparency |
| active | `increase-contrast` | contrast and border response |

Inactive-window evidence is required once per appearance. The accessibility variants isolate material
and contrast response, which window activation does not change.

## Machine record

Record once per session, in the ledger `notes` of the first row and in the session directory:

- `sw_vers` output (exact macOS point version);
- display model, native resolution, and the scaled resolution in use;
- `backing_scale` as printed by the probe;
- whether an external display was used.

A measurement taken at an unknown scale is not reproducible, and `os_version` is required on any
ledger row carrying geometry.

## Scale calibration

Every scene renders a calibration rule in its header: 20 alternating 10 pt segments, 200 pt total,
plus the printed `backing_scale`. Measure the rule in the capture first and derive the
pixel-to-point factor from it. Do **not** assume the factor from the display's advertised scale —
scaled display modes and the backing scale factor are not the same number.

If the rule does not measure to a clean multiple in a capture, that capture is unusable for geometry.
Record it as unusable rather than rounding.

## Running the probe

From the repository root on macOS:

```sh
swift build --package-path research/AppleReferenceLab -c release
```

Launch one scene at a time so the capture id is unambiguous:

```sh
GLASSLINE_REFERENCE_SCENE=buttons .build/release/AppleReferenceLab
```

`--scene=<id>` takes precedence over the environment variable. The header prints `scene_id` and
`appearance` so each capture self-identifies.

Toggling appearance, Reduce Transparency, and Increase Contrast is done in System Settings; the
`accessibility-states` scene reports the resolved environment values so the capture proves which
mode was actually active rather than which one was intended.

## Naming and storage

Name each file `<capture_id>.png`, matching `capture-manifest.csv` exactly. Captures are research
material and are **not** committed: they are not redistributable, and the repository ships no Apple
screenshots. Keep them in a session directory outside the repository and cite the `capture_id` in the
ledger.

## From capture to ledger

A row enters `measurement-ledger.csv` only after the named capture has been inspected. Classify every
value:

- `Observed` — measured from a capture, cited by `capture_id`;
- `Inferred` — derived by comparing sources;
- `Glassline decision` — chosen for Windows, not observed anywhere.

`eng/scripts/validate-measurement-ledger.ps1` enforces the schema, the classification vocabulary,
required confidence and asset-policy fields, `os_version` on any row carrying geometry, and that an
`Observed` AppleReferenceLab row cites a `capture_id` the manifest actually requires. It does not
require rows to exist — an empty ledger is an honest unfinished ledger, not a failure.

## Boundary

A completed capture set is reference evidence for macOS appearance. It is not a Glassline design
decision, not a Windows measurement, and not permission to freeze an unobserved number as a
compatibility contract.
